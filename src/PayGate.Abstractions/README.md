# PayGate.Abstractions

Provider-agnostic contracts and models for PayGate: payments, refunds, statuses, webhook events and errors. No dependencies beyond the .NET base class library.

> **Preview.** The contracts may still change before 1.0. See the [PayGate repository](https://github.com/hishamabdalla/PayGate).

Requires .NET 10 (`net10.0`).

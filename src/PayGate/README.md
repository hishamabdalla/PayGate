# PayGate

PayGate core: dependency-injection builder, gateway resolution, account and credential handling, payment-safe HTTP pipeline, signature and formatting helpers, and framework-agnostic webhook processing.

> **Preview.** This package has no public API yet. It is being built in phases; see the [PayGate repository](https://github.com/hishamabdalla/PayGate).

Requires .NET 10 (`net10.0`).
